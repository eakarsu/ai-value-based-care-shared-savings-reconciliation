# Value-Based Care Shared Savings Reconciliation

Independently calculate shared savings or losses and reconcile payer settlements and provider distributions.

**Primary buyer:** ACOs, provider groups, and health plans. **Evidence:** attribution, benchmarks, risk adjustment, claims, quality scores, expenditures, trend factors, corridors, shared-savings rates, settlements, and distributions.

Full local application built with React, Vite, Express, PostgreSQL, and OpenRouter. Includes 15 domain-specific capabilities, 105 custom AI workbench fields, three scenario-fill controls per feature, operational registers, workflow transitions, analytics, professional AI decision briefs, audit history, and at least 15 PostgreSQL records per capability.

## Domain capabilities

- Program agreement library
- Patient attribution reconciliation
- Benchmark construction
- Historical expenditure validation
- Trend factor calculation
- Risk adjustment validation
- Claim completion factor
- Quality score calculation
- Minimum savings rate
- Risk corridor calculation
- Shared savings calculation
- Shared loss calculation
- Payer settlement audit
- Provider distribution workflow
- Program performance analytics

Run `./start.sh`, then open <http://127.0.0.1:4658>. API: `5658`.

Administrator: `runtime-admin@example.com` / `LocalDemo!2026`. Operator and reviewer credential buttons are available on the login page.
